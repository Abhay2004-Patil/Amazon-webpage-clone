# 🛒 Amazon Clone Website
Amazon.in website UI clone developed using HTML and CSS as part of a TA activity. Includes case study of interface design and user experience.




---

## 📌 Project Overview

This project is a front-end clone of the Amazon website created as a TA activity case study.
It focuses on replicating the user interface and layout of a real-world e-commerce platform.

---

## 🚀 Features

✨ Responsive Homepage
🔍 Search Bar UI
🛍️ Product Listings
📦 Add to Cart Button (UI)
📱 Mobile-Friendly Design
🎨 Clean and Modern Layout

---

## 🧰 Technologies Used

- HTML5 – Structure of the website  
- CSS3 – Styling and layout design  
- Git – Version control  
- GitHub – Code hosting and deployment
